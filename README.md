# Apple Landing Page Clone

This repository is a static HTML/CSS practice project that recreates the layout style of an Apple product landing page.

## Main Concept

The page focuses on front-end layout practice: navigation, product hero sections, image placement, split promotional panels, and responsive visual structure. It is not connected to Apple and does not include ecommerce functionality.

## What It Includes

- Apple-style top navigation
- MacBook Pro hero section
- iPhone, Watch, Apple Card, Apple TV, and AirPods promotional blocks
- Local image assets under `images/`
- Custom CSS in `css/style.css`
- Font Awesome and Google Fonts references

## Tech Stack

- HTML
- CSS
- Static image assets

## Run Locally

Open `index.html` in a browser.

For a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Note

This is a learning project for front-end structure and visual replication.
